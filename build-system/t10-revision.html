🎯 Révision Mixte — why mixing matters

Until now every exercise told you which rule to apply. The board exam does not. This section removes the labels.

Practising one topic at a time

Feels easy — you already know the answer is a subjunctive, so you only have to conjugate.

This is blocked practice. It builds confidence but hides the hardest skill.

Practising everything mixed up

Feels harder — you must first identify what is being tested, then apply the rule.

This is interleaved practice. It feels worse and works better, because it trains the exact skill the exam measures.

🔑 The two-step habit: ① What is this question testing? ② What is the rule?
Students who skip step ① lose marks even when they know the grammar perfectly.

⚠️ The nine traps that cost the most marks

Verbes & Subjonctif

① être ou avoir ? — et l'accord du participe après être.

② Si + imparfait → conditionnel — jamais si j'aurais.

③ espérer que → indicatif, pas subjonctif.

④ quand + futur en français, présent en anglais.

Pronoms, négation, démonstratifs

⑤ rien avant le participe, personne après.

⑥ ne… que garde l'article ; ni… ni le supprime.

⑦ qui + verbe · que + sujet + verbe.

⑧ cet (masc. + voyelle) vs cette (fém.).

⑨ Le possessif s'accorde avec l'objet, pas le possesseur.

La stratégie

① Do the verbs first — it is compulsory and you have practised it most.

② Read all the optional questions before choosing. Pick the five you are surest of.

③ Leave the hardest for last, but attempt it — partial marks exist.

④ Re-read every answer for accents and agreement. That is where two or three marks hide.

🎯 Le calcul: Section C is 30 of 80 marks — more than reading and more than culture. It is also the most predictable section, because the rules never change. Marks here are the easiest to secure in the whole paper.

🕵️ Mettez les verbes au temps convenable

Exactly like the board: no tense is named. Read the highlighted clue word, decide the tense, then conjugate. Stuck? Press 💡 Hint.

1. Hier, il _____ (finir) ses devoirs.

hier = yesterday → one finished past action → use the Passé Composé.

2. Demain, nous _____ (partir) en voyage.

demain = tomorrow → a future plan → use the Futur Simple.

3. Quand j'étais petit, je _____ (jouer) au foot.

quand j'étais petit = a repeated past habit / background → use the Imparfait.

4. Tous les jours, elle _____ (prendre) le bus.

tous les jours = a habit true now (no past marker) → use the Présent.

5. Dès qu'il _____ (finir), il sortira.

dès que + an action completed before another future action → use the Futur Antérieur (aura + participle).

6. Si j'avais de l'argent, je _____ (voyager).

si + imparfait → the main clause takes the Conditionnel présent (never si j'aurais).

🕵️ Mettez les verbes au temps convenable

Same drill — spot the clue, deduce the tense, conjugate. These mix past, present, future, plus-que-parfait and subjunctive.

1. En ce moment, les enfants _____ (dormir).

en ce moment = right now → use the Présent.

2. La semaine dernière, nous _____ (visiter) le musée.

la semaine dernière = last week, finished → use the Passé Composé.

3. Autrefois, les gens _____ (écrire) des lettres.

autrefois = in the old days, habitually → use the Imparfait.

4. Quand je suis arrivé, il _____ déjà (partir).

déjà + an action finished before another past action → use the Plus-que-parfait (était + participle). Remember partir takes être.

5. Si tu viens, je _____ (être) content.

si + présent → the main clause takes the Futur Simple.

6. Il faut que tu _____ (être) à l'heure.

il faut que is a subjunctive trigger → use the Subjonctif (être → sois).
