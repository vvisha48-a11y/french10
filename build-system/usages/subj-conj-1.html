1a Usages · Les conjonctions déclencheurs
Où on l'utilise vraiment

Certaines conjonctions imposent le subjonctif

Some conjunctions carry the subjonctif with them automatically — no need to check for volition or emotion, the word itself is the trigger.

Je t'explique pour que tu comprennes.

I am explaining so that you understand.

La logique : each of these introduces something not yet a fact — a concession, a goal, a limit, a condition.

Attends jusqu'à ce que je revienne.

Wait until I come back — the return has not happened yet.

⚠️ AVANT QUE / APRÈS QUE — le piège symétrique.

avant qu'il parte ← subjonctif : ce n'est pas encore arrivé
après qu'il est parti ← indicatif : c'est déjà arrivé

Same shape, opposite mood — the board loves this pair.
