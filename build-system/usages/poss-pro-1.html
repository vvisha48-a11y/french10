1a Usages · Comparer sans répéter
Où on l'utilise vraiment

Le mien, le tien — le nom disparaît

Used to compare or to answer without repeating the noun. The article is part of the pronoun and can never be dropped.

— C'est ton stylo ? — Non, c'est le sien.

— Is this your pen? — No, it is his/hers.

Les formes : le mien / la mienne / les miens / les miennes — and likewise le tien, le sien, le nôtre, le vôtre, le leur.

Nos résultats sont bons ; les vôtres sont excellents.

Note the circumflex: the adjective is notre/votre, the pronoun is le nôtre/le vôtre.
